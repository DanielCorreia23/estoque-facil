# estoque-facil
Sistema web para controle de produtos e acompanhamento de validades em farmácias.
## Revisão técnica do MVP

Foi realizada uma auto-revisão técnica do projeto Estoque Fácil,
considerando a organização da arquitetura Flask, a estrutura
do banco de dados SQLite e as rotas de cadastro e consulta
de validade.

A revisão busca avaliar a organização do código, a legibilidade,
a validação dos dados recebidos e a segurança das operações
realizadas pelo sistema.
